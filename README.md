# 🎵 Audio Studio Web Pro

Editor de audio completo que funciona 100% en el navegador. Cambia el tono, agrega bajos, reverberación, ecualiza y descarga en MP3, WAV u OGG.

## ✨ Características

- **Ecualizador de 6 bandas**: Bajos, Medios Bajos, Medios, Medios Altos, Agudos, Presencia
- **Cambio de tono**: ±12 semitonos sin alterar la velocidad
- **Control de velocidad**: 0.5x a 2x
- **Reverberación**: Añade ambiente y profundidad
- **Panorámica estéreo**: Izquierda ↔ Centro ↔ Derecha
- **Compresor dinámico**: Iguala volúmenes
- **Volumen boost**: Hasta 150%
- **9 presets profesionales**: Rock, Pop, Jazz, Clásico, Bass Boost, Vocal, Nightcore, Slowed + Reverb
- **3 formatos de descarga**: WAV (sin pérdida), MP3 (320 kbps), OGG Vorbis
- **Visualizador en tiempo real**
- **100% privado**: Todo se procesa localmente, no se sube nada a servidores

## 🛠️ Tecnologías

- Web Audio API
- Tailwind CSS
- lamejs (codificación MP3)
- MediaRecorder API (OGG)

## 📦 Cómo usar

1. Visita la [página web](https://tu-usuario.github.io/audio-studio/)
2. Arrastra un archivo de audio o haz clic para seleccionar
3. Ajusta los efectos a tu gusto
4. Elige el formato y descarga
